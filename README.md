# 🎮 Interactive Role-Playing Game (Java)

A fully interactive RPG developed entirely in **Java** with no external libraries.  
Features a content-aware game engine with dynamic object interaction, NPC behaviors, and dialogue systems.

---

## ✨ Features
- Tile-based map rendering
- Player movement & environment interaction
- Non-playable characters (NPCs) with unique dialogues
- Event and behavior system
- Built using OOP principles (inheritance, polymorphism, encapsulation)

---

## 🛠 Tech Stack
- **Language:** Java
- **Core Concepts:** OOP, 2D arrays, game loop, event handling
